# Platform Base

Source type: base product knowledge
Commerce truth: Shopify owns price, availability, variants, cart, and checkout.
Use this file only for general base guidance.

The Platform Base is the simple non-motion base option for customers who want stable support without adjustable movement.

Use this guidance when the shopper asks about:

* simple base support
* non-motion setup
* keeping the setup straightforward
* mattress-only versus base-supported setup

Do not use this file for:

* live pricing
* availability
* cart
* checkout
* variant IDs

If the shopper asks for price or availability, resolve through Shopify.
