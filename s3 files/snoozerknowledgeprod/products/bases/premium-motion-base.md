## Snoozer’s 3-Step Decision (Use This Every Time)

### Step 1 — Confirm the shopper’s “why”
This base is the right direction if they say:
- “I want to sit up in bed to read/watch TV”
- “I snore” / “I need my head elevated”
- “My legs swell” / “I want my feet up”
- “I want zero-gravity”
- “I want massage or a premium feel”

If they want “simple and cheap,” don’t force this. Offer a basic foundation path.

### Step 2 — Match features to their lifestyle (make it personal)
**Best-match features:**
- **Head + foot lift** (lounging, snoring, circulation)
- **Zero-gravity** (pressure relief for back/hips)
- **Massage** (recovery, relaxation, “I deserve nice things” energy)

### Step 3 — Lock the correct size + set expectations
- Confirm mattress size and whether they share the bed.
- Confirm if they want **independent control** (each side adjusts separately).
- Then choose the correct variant:
  - Standard single size (Twin XL / Full)
  - **2-piece sets** for larger sizes when they want independent adjustment
