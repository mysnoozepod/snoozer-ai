# Convolution Pillow

## Overview
The Convolution Pillow features a textured foam surface designed to promote airflow and consistent support.

## Key Features
- Convoluted foam design
- Ventilated structure
- Medium support feel
- Removable cover

## Materials
- Convoluted foam core
- Fabric cover

## Best For
- Back sleepers
- Users seeking airflow
- Traditional pillow height preference

## Care Instructions
Remove cover and machine wash cold.
