# Production Equipment Comparison

## Purpose

This document compares equipment candidates against MySnoozePod’s production-grade standard.

The goal is to avoid buying or building sensor hardware that works once but cannot survive daily showroom use.

## Comparison Criteria

Each candidate should be scored from 1 to 5.

1 = Poor  
3 = Acceptable  
5 = Strong

## Required Review Categories

### Mounting

Questions:

- Can it be mounted safely?
- Can it be hidden or presented cleanly?
- Can it survive shopper contact?
- Can it survive cleaning?

### Power

Questions:

- Is power stable?
- Can the cable be secured?
- Does it recover after power loss?
- Is there any fire, trip, or cable risk?

### Network

Questions:

- Can it connect reliably?
- Can it use a secure path?
- Can it identify itself?
- Can dev and prod devices be separated?

### Reliability

Questions:

- Does it produce clean events?
- Does it avoid false positives?
- Does it avoid missed events?
- Can it send heartbeat?
- Can it report faults?

### Maintenance

Questions:

- Can Langston inspect it?
- Can Care document it?
- Can Ty approve it?
- Can Codi eventually build against its output?
- Can it be replaced without redesigning the whole system?

### Showroom Fit

Questions:

- Does it look professional?
- Does it stay out of the shopper’s way?
- Does it protect the MySnoozePod brand?
- Would we be comfortable deploying this in the real showroom?

## Decision Values

Use these decision values:

- Researching
- Candidate
- Test
- Approved for Pilot
- Rejected
- Deferred

## Final Rule

The winning device is not the coolest device. The winning device is the one that is reliable, clean, serviceable, and useful.
