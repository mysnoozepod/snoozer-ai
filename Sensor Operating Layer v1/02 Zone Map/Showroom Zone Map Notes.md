# Showroom Zone Map Notes

## Purpose

This document captures physical showroom observations that affect sensor placement, zone definitions, and testing.

Langston should use this file when walking the showroom layout. Care should keep the notes organized and translate them into the Zone Dictionary, Device Matrix, and Test Logs.

## Mapping Goal

The goal is to understand the physical showroom before choosing devices or writing code.

The team needs to know:

- Where shoppers enter
- Where shoppers naturally pause
- Where the welcome kiosk sits
- Where each pod sits
- Where wiring and power can safely live
- Where false positives may happen
- Where sensors could be bumped, blocked, or abused
- Where Snoozer should speak
- Where Snoozer should stay quiet

## Walkthrough Checklist

### Entry

- Where does the shopper first enter?
- Is the entry path narrow or wide?
- Could employees, delivery workers, or passersby trigger the zone?
- Is there a clean mounting point?
- Is power available nearby?

### Welcome Kiosk

- Can the shopper stand naturally at the kiosk?
- Is the kiosk close enough to entry that the zones may overlap?
- Could someone pass by the kiosk without using it?
- Does the kiosk already provide enough digital activity data?
- Would a sensor add value here?

### Pods

For each pod:

- Where would the sensor be mounted?
- Can the sensor detect actual mattress use?
- Can the sensor avoid detecting someone walking past?
- Can the device survive bed movement, cleaning, and resets?
- Can wiring be hidden and secured?
- Can the pod be serviced without breaking the sensor?

### Accessory Zones

- Are pillows and bedding separate enough to track?
- Is touch detection needed?
- Is presence detection enough?
- Would accessory sensors create useful business data?
- Would prompts here feel helpful or annoying?

### Help Zone

- Where should a help trigger live?
- Should help be a physical button, kiosk option, HUD option, or all of the above?
- Can the help trigger be tested easily?
- What happens if help hardware fails?
